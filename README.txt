# VANABHOOMI Website

இது VANABHOOMI YouTube channel-க்காக உருவாக்கப்பட்ட responsive static website.

## Files
- `index.html` — Website structure
- `style.css` — Design & responsive styling
- `script.js` — Mobile menu, year, share button
- `assets/vanabhoomi-logo.jpg` — நீங்கள் upload செய்த logo/image

## பயன்படுத்துவது
1. ZIP-ஐ extract செய்யவும்.
2. `index.html`-ஐ browser-ல் திறக்கவும்.
3. உங்கள் hosting-ல் `index.html`, `style.css`, `script.js`, `assets/` ஆகியவற்றை upload செய்யவும்.
